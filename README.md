# ABA Skills Assessment Platform

The ABA Skills Assessment Platform is a multi-tenant, compliant SaaS designed to digitize clinical assessments (like ABLLS-R, VB-MAPP) while respecting intellectual property laws. It allows clinics to manage learner assessments securely and efficiently.

## 🚀 Quick Start

### Prerequisites
- Node.js 20+
- Supabase CLI

### Setup

1.  **Clone the repository**
    ```bash
    git clone <repository_url>
    cd DomainA_Tool
    ```

2.  **Install Dependencies**
    ```bash
    cd frontend
    npm install
    ```


3.  **Run Development Server**
    See the [Setup Guide](docs/guides/setup_guide.md) for detailed instructions.
